# Обновление иконки приложения: плоский минимализм

## Что делаем

Сделать иконку приложения ещё более плоской и минималистичной, близкой к загруженному референсу: жёлтая округлая коробочка с несколькими цветными бумажками, торчащими сверху, без объёмной крышки, теней и тёмных обводок. Основные цвета бумажек — жёлтый, голубой, зелёный, красный, фиолетовый. Иконка должна оставаться узнаваемой для КОРОБОЧКИ, но быть максимально простой и спокойной для людей с СДВГ.

## Зачем

- Текущая иконка в репозитории (`public/icon-192.svg`) всё ещё содержит объёмную крышку, перспективу, четыре развернутые бумажки и тёмные обводки — при уменьшении мелкие детали сливаются.
- Загруженный референс показывает более чистый вид: одна округлая коробка + 3 яркие прямоугольные бумажки сверху, без лишних линий.
- Плоская иконка лучше читается на телефоне, в списке приложений, в PWA и как favicon.

## Что обновляем

- Основные PWA-иконки: `public/icon-192.svg`, `public/icon-512.svg`.
- Maskable-иконки: `public/icon-maskable-192.svg`, `public/icon-maskable-512.svg`.
- Favicon: `public/favicon.jpg` → `public/favicon.png` (или SVG).
- OG/social preview и splash-изображение в `index.html`.
- При необходимости — `manifest.json`/`vite.config.ts` для PWA.

## Как делаем

1. **Визуальные варианты.** Сгенерировать 3 направления плоской иконки на основе загруженного референса: разные формы коробки (круглая, с закруглёнными углами, чуть вытянутая), разное количество и расположение бумажек, разные цветовые акценты. Показать пользователю для выбора.
2. **Финальная иконка.** По выбранному направлению создать SVG-варианты для 192×192, 512×512 и maskable-версий. Maskable-вериант — упрощённая композиция с запасом по краям, чтобы не обрезалась маской Android.
3. **Растровые производные.** Из финального SVG сделать:
   - `favicon.png` 64×64,
   - OG/splash PNG 1200×630 или 1920×997 (как сейчас `assets/how-it-works.png`).
4. **Подключение.** Обновить `<link rel="icon">`, `<link rel="apple-touch-icon">`, `og:image`, `twitter:image` в `index.html`.
5. **Проверка.** Собрать проект, убедиться, что иконки отображаются в превью, нет ошибок сборки, favicon подхватывается.

## Критерии готовности

- Все SVG-иконки — плоские, без градиентов и теней.
- Композиция читается при 192×192 и 64×64.
- Favicon и OG-изображение соответствуют выбранному стилю.
- Сборка (`bun run build`) проходит без ошибок.
