# Знакомство с Коробочкой: категории в центре

Основа — система мотивационной гигиены Виолетты Макеевой. Главная мысль: человеку не нужно решать, куда положить дело — отделения уже придуманы, Коробочка раскладывает сама. Про «дофамин и завершение» ничего не говорим.

## 1. Как это будет реализовано (ответ на вопрос)

Никакого Remotion и рендеринга видео в коде. Два независимых куска:

- **Внутри приложения** — обычные экраны и карточки на том же React/Tailwind, что и остальная Коробочка. Это работает сразу в превью, ничего не весит, не устаревает.
- **Само видео** — вы снимаете живьём (улица + запись экрана телефона) по сценарию, который я записываю в файл проекта. Готовый ролик потом заливается на YouTube/RuTube, а в приложении в уже подготовленное окно вставляется ссылка. Менять интерфейс второй раз не понадобится.

## 2. Онбординг — 4 шага, с акцентом на отделения

1. **Дела не бывают одинаковыми** — коротко про систему: «обязательные», «безопасность», «простые радости», «эго-радости», «доступность радостей». Не «срочно/важно», а по типу ресурса.
2. **Сваливай всё в кучу** — голосом или текстом в «Разбор»; сортировать самой не нужно, это самое сложное — и это делает Коробочка.
3. **Жми на коробочку** — одно дело за раз, с таймером.
4. **Большие цели — не страшно** — описал проект, ИИ разложил на спокойные шаги.

Финал: «Дела — по полочкам. В голове — тишина.» и кнопка «Начать».

## 3. Кнопка «Как устроена Коробочка»

- В настройках рядом с «Что нового».
- Открывает окно знакомства: наглядное объяснение пяти отделений (что туда попадает, живые примеры), те же 4 карточки и блок для видео.
- Доступна в любой момент, не только при первом входе.

## 4. Окно для видео

- Блок «Видео-инструкция» с аккуратным плеером-плейсхолдером под YouTube/RuTube.
- Пока ролика нет — карточки-объяснения и подпись «Видео скоро появится».

## 5. Сценарий видео в файл `docs/video-script.md`

Не виден пользователям приложения, только для съёмок.

- Крючок: улица, в голове одновременно врач и анализы, жёлтая краска для горшка, осадок от ворчания, шелест листьев, «блинчики-оладушки, были мы у бабушки».
- Центральный момент — снятие мук сортировки: «не нужно думать, куда положить — система уже есть».
- Покадровый план (~2 мин) + 60-сек нарезка для Shorts/Reels:
  1. 0:00–0:25 «Шум в голове» — улица, живая съёмка.
  2. 0:25–0:45 «Выгрузка» — «Разбор», микрофон или «Попробовать пример».
  3. 0:45–1:20 «Система отделений» — поток распадается: врач → обязательные, горшок → проект в радостях, мысли и «блинчики» → заметки. Голос объясняет пять отделений.
  4. 1:20–1:40 «С чего начать» — клик по коробочке, случайная задача, таймер.
  5. 1:40–1:55 «Большие цели без страха» — проект «Расписать керамический горшок», шаги с ИИ.
  6. 1:55–2:05 Финал — логотип и титр.
- Отдельный список русских титров.
- Анимации не акцентируем — действие просто происходит в кадре.
- Упоминание первоисточника: методика Виолетты Макеевой (формулировку согласуем перед съёмкой).

## Порядок работы

Онбординг → окно «Как устроена Коробочка» с объяснением отделений → блок под видео → файл сценария → проверка сборки и в браузере. Публикация в конце.
