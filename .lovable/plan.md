# Ничего не пропадает после «Разбора» + сценарий видеоинструкции

## Часть 1 — контекст и мысли не пропадают после разбора

Сейчас карточки «не задача» (мысли, суммы, чужие слова) и задачи, с которых сняли галочку, после разбора никуда не сохраняются — пропадают.

Правка:

- При закрытии разбора (или после «Добавить выбранное») все неподтверждённые карточки — и «не задача», и невыбранные задачи — автоматически сохраняются как заметки (`addNote` из существующего `src/lib/notes.ts`). Никаких вопросов, просто тихий toast «Остальное сохранила в заметки».
- Такие заметки сохраняются с флагом `processed: true`, чтобы счётчик «Разбор · N» не рос и не создавал ощущение долга.
- В блоке «Накопленные заметки» добавляется свёрнутая строка «Обработанные · N»: раскрывается по щелчку, каждая заметка с кнопкой удаления. По умолчанию скрыты — мусор не давит.
- Отдельного места «Контекст» не делаем — одна система заметок вместо двух похожих.

### Технические детали

- `src/components/BraindumpPanel.tsx` — при уходе с экрана/применении черновика собрать `items` без `selected` и «not_task», вызвать `addNote` с готовым текстом карточки (вид «не задача» можно пометить префиксом, например «(контекст) текст» — обсудим на превью).
- `src/lib/notes.ts` — без изменений по схеме, уже есть `processed`.
- `BraindumpPanel.tsx`, блок заметок — экспандер «Обработанные · N» (список заметок с `processed: true`), кнопка «Удалить» у каждой.

## Часть 2 — сценарий видеоинструкции

## Цель

Понятный, небыстрый по смыслу, но быстрый по темпу моушн-ролик без закадрового голоса: зритель смотрит и сам всё видит. Снимает нагрузку «искать функции и разбираться». Используется и внутри приложения (онбординг / «О приложении»), и снаружи (GitHub, соцсети).

Формат: анимированные сцены (Remotion), крупный текст на экране, подсказки-титры, спокойная музыка. Без CTA-кнопок и навигации внутри видео.

Ориентир по длительности: 3–3.5 минуты — всё приложение, без воды. Плюс из тех же сцен собирается короткая версия ~60 сек для соцсетей.

## Что делаем сейчас

**Только сценарий.** Рендер видео — следующий шаг, после того как сценарий одобрен.

Результат этого шага: документ в файлах — `Коробочка-видео-сценарий.md`.

## Структура сценария

Каждая сцена описана одинаково:

- тайминг (секунды);
- что происходит на экране (визуал: интерфейс, анимация, переход);
- титры на экране (текст);
- настроение/звук.

### Блок 1 — Крючок (0–15 сек)
Проблема изнутри: «мысли крутятся, список пугает, неясно с чего начать» → коробочка, в которую бумажки просто складываются.

### Блок 2 — Суть метода (15–50 сек)
Шесть отделений (Обязательные, Безопасность, Простые радости, Эго-радости, Доступность радостей) + цикл: записал → коробочка выбирает за тебя → таймер → честный результат.

### Блок 3 — Ежедневный цикл (50–110 сек)
Быстрое добавление (текст/голос, задача или заметка), случайная вытяжка, таймер (включая «Ещё 5/10/15 мин» и «Вернуть в коробочку»), удаление с «Отменить».

### Блок 4 — Разбор (110–150 сек)
Поток мыслей → ассистент раскладывает на карточки: задача/событие/проект/повтор/контекст. Ничего не сохраняется без подтверждения. Накопленные заметки подхватываются разбором.

### Блок 5 — Проекты и повторы (150–190 сек)
Проекты-чеклисты («по порядку / в любом порядке»), «С чего начать?», «Застряла», повторяющиеся задачи с точным временем.

### Блок 6 — Календарь, поиск, напоминания (190–215 сек)
Календарь с датами и задачами, поиск и фильтры, напоминания со звуком.

### Блок 7 — Настроение и приватность (215–240 сек)
Светлая/тёмная/3D-главная, свой ИИ-ключ (ключи хранятся только на устройстве), офлайн PWA.

### Финал (240–260 сек)
«Коробочка держит дела, чтобы вы держали голову». Название и логотип.

## Как не переписывать сценарий после доработки приложения

- Сцены разбиты на модули: базовые сцены (метод, вытяжка, таймер) не трогаем никогда.
- Для функций из плана, которых ещё нет (анимации складывания/сгорания, «Сценарии», режим «Нет сил»), в сценарии помечены места-вставки и готовые формулировки — добавим сцену, не пересобирая остальное.
- В конце документа — чек-лист соответствия: какая сцена какому пункту приложения соответствует, обновляется при каждой версии.

## Порядок работы

1. Пишу сценарий целиком (визуал + титры + тайминги) в файл.
2. Вы читаете и правите формулировки под себя.
3. Отдельным шагом (по согласованию) делаю сам ролик в Remotion: сначала 1–2 пробные сцены для утверждения стиля, потом полный рендер MP4 + короткая 60-сек версия.
