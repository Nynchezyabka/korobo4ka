# Упростить подсказки шагов в проектах

## Что изменится

- Убрать отдельную кнопку «Подсказать шаги»: сейчас она показывает заранее записанные варианты и по смыслу дублирует готовые чек-листы.
- Оставить «Библиотеку чек-листов» как сворачиваемый источник типовых планов. Она работает без нейросети и остаётся доступной внутри проекта.
- В форме нового проекта дать два ясных действия:
  - **«Создать»** — создать пустой проект;
  - **«Создать и предложить шаги»** — создать проект и сразу запросить у AI персональные шаги по его названию.
- В уже созданном проекте оставить одно AI-действие **«Предложить шаги с AI»**, чтобы запрос можно было повторить позже.
- Под AI-действием показывать кликабельную подпись текущей модели и тот же выбор источника/модели, что уже используется в «Разборе»: демо, подключённые модели и встроенный вариант владельца.
- Результат не добавлять автоматически: показать блок «Предложенные шаги», где можно взять один шаг или добавить все. Так нейросеть ничего не меняет без подтверждения.
- Заменить текст пустого проекта на: **«Шагов пока нет. Добавьте вручную или воспользуйтесь подсказками ниже.»**

## Как это будет восприниматься

- **«Разбор»** остаётся отдельным местом для потока мыслей, задач, проектов и контекста.
- **AI в проекте** решает только одну задачу: предлагает шаги для конкретного проекта.
- **Готовые чек-листы** остаются обычными шаблонами без AI.
- Термины «Подсказать шаги» и «Спросить AI» больше не конкурируют друг с другом.

## Технические детали

- Вынести уже существующий выбор модели из «Разбора» в общий элемент и использовать его в обоих местах, чтобы выбор синхронизировался автоматически.
- Сохранить текущий вызов AI для декомпозиции проекта и текущий интерфейс подтверждения предложенных шагов.
- Не менять порядок выполнения проекта «По порядку / В любом порядке», хранение проектов и существующие чек-листы.
- Проверить создание проекта обоими способами, смену модели, повторный запрос шагов, выбор отдельных шагов и «Добавить все» на мобильном и широком экране.
