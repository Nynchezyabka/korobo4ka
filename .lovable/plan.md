# Помощник: один простой блок настроек + версия 6.1

## 1. Старые версии приложения и ваши лимиты — уже закрыто

Проверка защиты сделана на сервере, а не в приложении, поэтому старая установленная версия ничего не сможет потратить:

- Запрос без кода владельца получает отказ «Встроенный ИИ доступен только владельцу».
- Это проверено вживую: старый вариант запроса (как его шлёт прежняя версия) вернул отказ.
- Обновлять приложение у других людей не требуется — старые копии просто перестанут пользоваться встроенным помощником и смогут работать в демо-режиме или со своим ключом.

Дополнительно в этом обновлении: у демо-режима есть общий счётчик на 50 разборов, так что и он не может быть выкачан бесконечно.

## 2. Настройки помощника — свести в один понятный блок

Сейчас в настройках два соседних раздела («Режим ИИ» и «Свои ИИ-ключи»), и вместе они выглядят перегруженно. Объединяем в один раздел **«Помощник»** с простым выбором из списка:

```text
Помощник
( ) Демо — без настроек, осталось 49 из 50 разборов
( ) Мой ключ: DeepSeek · deepseek-chat        [модель v] [удалить]
( ) Мой ключ: OpenRouter · ...                [модель v] [удалить]
( ) Встроенный — только для владельца

        + Подключить свой ключ
        Код владельца
```

Правила упрощения:

- Один список — один выбор. Демо, каждый подключённый ключ и встроенный режим стоят в одном ряду, выбирается один пункт.
- Настройка модели видна только у выбранного ключа, у остальных скрыта.
- «Подключить свой ключ» и «Код владельца» спрятаны под раскрывающиеся строки — открываются, только когда нужны.
- Пункт «Встроенный» показывается только тому, кто ввёл код владельца; остальным он не мозолит глаза.
- Пояснения ужимаются до одной короткой фразы на весь блок.

Итог: вместо двух разделов и десятка элементов — один список и две скрытые строки.
