# Обновление иконки приложения: плоский минимализм

## Что делаем

Заменить текущую объёмную иконку «коробочка с бумажками» на плоскую минималистичную версию в пяти акцентных цветах (жёлтый, голубой, зелёный, красный, фиолетовый). Иконка должна оставаться узнаваемой для приложения КОРОБОЧКА, но быть проще и спокойнее для людей с СДВГ — без лишних деталей, теней и визуального шума.

## Зачем

- Текущая иконка объёмная и детализированная; в маленьком размере мелкие элементы сливаются.
- Плоский минималистичный стиль лучше читается на телефоне, в списке приложений и на рабочем столе.
- Пять цветов бумажек отражают категории задач внутри приложения.

## Что обновляем

- Основные PWA-иконки: `public/icon-192.svg`, `public/icon-512.svg`.
- Maskable-иконки: `public/icon-maskable-192.svg`, `public/icon-maskable-512.svg`.
- Favicon: `public/favicon.jpg` → `public/favicon.png` (или SVG, если выбран вектор).
- OG/social preview и splash-изображение в `index.html`.
- При необходимости — `manifest.json`/`vite.config.ts` для PWA.

## Как делаем

1. **Визуальные варианты.** Сгенерировать 3 направления плоской иконки с разным расположением коробочки и бумажек, сохранив цветовую схему. Показать пользователю для выбора.
2. **Финальная иконка.** По выбранному направлению создать SVG-варианты для 192×192, 512×512 и maskable-версий. Maskable-вериант — упрощённая композиция с запасом по краям, чтобы не обрезалась маской Android.
3. **Растровые производные.** Из финального SVG сделать:
   - `favicon.png` 64×64,
   - OG/splash PNG 1200×630 или 1920×997 (как сейчас `assets/how-it-works.png`).
4. **Подключение.** Обновить `<link rel="icon">`, `<link rel="apple-touch-icon">`, `og:image`, `twitter:image` в `index.html`.
5. **Проверка.** Собрать проект, убедиться, что иконки отображаются в превью, нет ошибок сборки, favicon подхватывается.

## Критерии готовности

- Все SVG-иконки — плоские, без градиентов и теней.
- Композиция читается при 192×192 и 64×64.
- Favicon и OG-изображение соответствуют выбранному стилю.
- Сборка (`bun run build`) проходит без ошибок.
