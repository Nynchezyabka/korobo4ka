# Видео и знакомство с приложением

Две части: то, что делается прямо в приложении, и сценарий видео для съёмки.

## 1. Обновить экран приветствия (онбординг)

Сейчас он устарел: 5 шагов с упоминанием шаблонов и статистики, которых в реальном первом опыте почти не видно. Заменить на 3 честных шага:

1. **Сваливай всё в кучу** — голосом или текстом в «Разбор»; можно просто поговорить, приложение само отделит дела от мыслей.
2. **Жми на коробочку** — одна задача за раз, с таймером; не нужно решать всё сразу.
3. **Большие цели — не страшно** — опиши проект, ИИ разложит его на спокойные шаги.

Финальный шаг: слоган «Дела — по полочкам. В голове — тишина.» и кнопка «Начать».

## 2. Кнопка «Как устроена Коробочка»

- В настройках, рядом с «Что нового» (иконка Video/Play).
- Открывает окно-знакомство: те же 3 карточки из онбординга + раздел «Посмотреть видео».
- Доступна в любой момент, не только при первом входе.

## 3. Окно для видео

- Внутри окна-знакомства — блок «Видео-инструкция»: аккуратный плеер-плейсхолдер под YouTube/RuTube.
- Пока видео не снято: вместо плеера — наглядные карточки (как в онбординге) и подпись «Видео скоро появится».
- Когда будет готов ролик — вставляем ссылку на YouTube/RuTube, менять интерфейс больше не нужно.

## 4. Записать сценарий видео в файл проекта

Файл `docs/video-script.md` (не виден пользователю приложения, для съёмок):

- Концепция: человек идёт по улице, в голове одновременный шум — врач и анализы, жёлтая акриловая краска для горшка, осадок от ворчания мужа, шелест листьев, «блинчики-оладушки, были мы у бабушки».
- Покадровый план 2–2,5 мин + 60-сек нарезка для Shorts/Reels:
  1. «Шум в голове» (0:00–0:25) — улица, живая съёмка, хаотичные мысли.
  2. «Выгрузка» (0:25–0:50) — телефон, «Разбор», микрофон или кнопка «Попробовать пример».
  3. «Магия порядка» (0:50–1:20) — поток распадается: врач → задача, мысли и «блинчики-оладушки» → заметки, «расписать горшок» → проект.
  4. «Не знаешь, с чего начать?» (1:20–1:45) — 3D-главная, клик по коробочке, случайная задача и таймер.
  5. «Дофамин и завершение» (1:45–2:10) — задача сделана; действие просто происходит в кадре, без акцента на анимации.
  6. «Большие цели без страха» (2:10–2:30) — проект «Расписать керамический горшок», «Предложить шаги с AI».
  7. Финал (2:30–2:45) — логотип и титр.
- Анимации в сценарии не акцентируются — просто действие в кадре (согласовано).
- Отдельный список русских титров/надписей (вместо кальки «держать голову»: вариант «Дела — по полочкам. В голове — тишина.»).

## Порядок работы

1. Онбординг (3 шага) → 2. Кнопка «Как устроена Коробочка» → 3. Окно с плейсхолдером видео → 4. Файл со сценарием → проверка сборки и в браузере.

Публикация — отдельно, в конце (чтобы онбординг увидели живые пользователи).
