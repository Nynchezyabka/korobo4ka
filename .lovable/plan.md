# Мелкие улучшения для ежедневного входа

Цель: сделать так, чтобы простые задачи вроде «позвонить свекрови завтра в обед» не терялись, и чтобы для задачи без шагов сразу было понятно, с чего начать сегодня. Без новых больших разделов.

## Что делаем

### 1. Напоминание к конкретной задаче
Сейчас напоминание можно задать только при добавлении через `QuickAddBar`. Если задача уже есть — нельзя.

- Добавить в меню задачи (три точки / «Ещё») пункт «Напомнить».
- Открывать маленький диалог с выбором даты и времени.
- Сохранять `scheduledFor` в задачу и ставить `setTaskReminder` через существующий `src/lib/notifications.ts`.
- Показывать на карточке задачи иконку колокольчика, если напоминание установлено.
- При отмене/выполнении задачи очищать напоминание.

Это позволит добавить задачу сейчас, а напоминание поставить потом — без планирования на лету.

### 2. Личная приватная заметка в настройках
Список ваших блоков («не понимаю, что делать», «страшно», «должна» и т.д.) нужен вам как справочник, а не всем пользователям.

- Добавить в `SettingsModal` сворачиваемый блок «Моя заметка» (по умолчанию свёрнут).
- Текстarea только для вас, хранится в `localStorage`.
- Не экспортируется и не синхронизируется.
- Можно использовать как чек-лист при разборе застрявшей задачи.

### 3. «С чего начать?» прямо в списке задач
Сейчас инструмент «С чего начать?» (Next Minute Sheet) доступен только внутри таймера. Для задачи без шагов неочевидно, куда тыкать.

- Для задач, которые не входят в проект и не имеют микро-шагов, показать в карточке небольшую кнопку/подсказку «С чего начать?» (иконка лампочки).
- По клику открывать существующий `NextMinuteSheet` для этой задачи — без запуска таймера.
- Это сразу отвечает на вопрос «что делать с этой задачей сегодня».

## Как уже сейчас запланировать звонок свекрови

Пока план не реализован, можно сделать через `QuickAddBar` внизу экрана:

1. Напишите: «Позвонить свекрови про желе».
2. Нажмите кнопку «время» → выберите 12:00 (или 13:00).
3. Нажмите «+».

Задача появится в «Все задачи», а в назначенное время придёт уведомление — если уведомления включены в настройках.

Или голосом: «Позвонить свекрови про желе завтра в обед» — приложение само поставит время.

## Что не делаем

- Не создаём отдельный раздел «Мои блоки» на главной — чтобы не перегружать боковую панель.
- Не меняем структуру Task — добавляем только уже существующее поле `scheduledFor` и функцию `setTaskReminder`.
- Не добавляем новый скин или темы — правки только UX.

## После реализации

- Проверить, что напоминание действительно срабатывает (локально через тестовое уведомление).
- Проверить мобильную версию: диалог выбора времени не должен вылезать за экран.
- Проверить, что кнопка «С чего начать?» не появляется у задач, которые уже внутри проекта (у них есть свои шаги).
