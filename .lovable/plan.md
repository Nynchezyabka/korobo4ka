# 3D-режим: щелчок по коробочке даёт случайную задачу

## Что изменится

- Щелчок по самой коробочке сразу выдаёт случайную задачу из её группы и открывает таймер — как на карточках обычной главной.
- На круглой этикетке коробочки появляются две маленькие кнопки, как на присланном примере:
  - значок списка (слева) — открыть задачи этой группы;
  - плюс (справа) — добавить задачу в эту группу.
- Всплывающая панель с тремя кнопками внизу экрана убирается: действия теперь прямо на коробочке.
- Щелчок по бумажке внутри коробочки по-прежнему открывает таймер с этой задачей.

## Мой вариант оформления

Кнопки рисуются не как HTML поверх сцены, а как две небольшие круглые области прямо на этикетке — так они всегда «приклеены» к нужной коробочке и не сбиваются при повороте/перестроении сцены. Они подсвечиваются при наведении и увеличены до удобного размера для пальца на телефоне.

Если в группе нет доступных задач, щелчок по коробочке показывает короткое сообщение «в этой коробочке пока пусто», а плюс остаётся рабочим.

## Технически

- `src/components/three/Box3D.tsx`: добавить два интерактивных меша (значок списка и плюс) на этикетку — в альбомной ориентации на верхней этикетке крышки, в стопке на передней этикетке. Иконки рисуются в текстуру рядом с надписью (`makeLabelTexture`) либо отдельными спрайтами; hover меняет прозрачность/масштаб.
- Клик по корпусу коробочки вызывает новый проп `onRandom(def)` вместо `onSelect`; клики по кнопкам останавливают всплытие (`e.stopPropagation()`).
- `src/components/three/Scene.tsx`: пробросить `onRandom`, `onViewTasks`, `onAdd` в `Box3D`; состояние `openBox` остаётся только для анимации открытия крышки при выборе случайной задачи (кратковременное открытие) — камера продолжает работать как сейчас.
- `src/components/ThreeDashboard.tsx`: удалить нижнюю панель действий, вызывать `onRandomTask(box.categories)`, `onViewTasks(box.categories)` и `openAddModal(box.categories[0], box.categories)` напрямую из сцены. Соответствующие CSS-правила `.three-actions` / `.three-action-button` в `src/index.css` убрать.
- Проверка в браузере: скриншот сцены, клик по коробочке (открывается таймер), клик по значкам списка и плюса, мобильная и десктопная раскладки, чистая консоль.
