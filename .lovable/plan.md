# Демо-режим разбора: 50 бесплатных попыток на всех

## Что увидит посетитель

- В разделе «Разбор» появляется переключатель источника: **Встроенный ИИ · Мой ключ · Демо**.
  Демо доступно сразу, без настроек и без входа в аккаунт.
- Под полем ввода — строка «Демо: осталось N из 50 разборов».
- Когда 50 разборов израсходованы, кнопка демо гаснет и появляется текст:
  «Демо-лимит исчерпан. Подключите свой ключ в настройках или используйте встроенный ИИ».
- Обычные режимы (встроенный ИИ и свои ключи) работают ровно как сейчас — их эта доработка не касается.

## Как это устроено

- Демо-запросы идут в отдельную серверную функцию, которая обращается к DeepSeek
  **отдельным демо-ключом**. Ключ живёт только на сервере: в коде приложения его нет,
  в сетевых запросах браузера он не виден.
- Счётчик — одна строка в базе на сервере. Он общий для всех посетителей,
  переживает перезагрузку и очистку браузера, к людям не привязан
  (никаких имён, IP или идентификаторов не сохраняем).
- Счётчик увеличивается только после успешного ответа модели: неудачные запросы
  лимит не съедают.
- Обнулить счётчик или поднять лимит можно в любой момент — попросите меня,
  это одна операция в базе. Замена демо-ключа — тоже одна операция, код не меняется.

## Что понадобится от вас

Отдельный ключ DeepSeek (не тот, которым пользуетесь сами) — создайте новый
в кабинете DeepSeek и положите на него небольшую сумму. Я запрошу его через
защищённую форму: он попадёт сразу в хранилище секретов, минуя чат и код.

## Техническая часть

**База (миграция):** таблица `public.demo_usage` — одна строка
(`id text primary key`, `used int not null default 0`, `limit_total int not null default 50`,
`updated_at timestamptz`). RLS включена, политик на чтение/запись для `anon`/`authenticated` нет —
таблицу трогает только edge-функция через service role. GRANT: `select` для `anon` не выдаём,
`GRANT ALL ... TO service_role`.

**Секрет:** `DEMO_DEEPSEEK_API_KEY` (через add_secret).

**Новая edge-функция `supabase/functions/demo-braindump/index.ts`:**
- `GET`-подобный вызов с `{ action: "status" }` → `{ used, limit, left }` для отображения счётчика.
- `{ action: "parse", text, today }`:
  1. атомарный инкремент через SQL-функцию `public.demo_consume()` (SECURITY DEFINER,
     `update demo_usage set used = used + 1 where id='global' and used < limit_total returning used`);
     пустой результат → 429 с сообщением «Демо-лимит исчерпан»;
  2. запрос в `https://api.deepseek.com/v1/chat/completions`, модель `deepseek-chat`,
     системный промпт и JSON-схема — те же, что в `src/lib/aiPrompts.ts`/`parse-braindump`,
     но с `response_format: { type: "json_object" }` (DeepSeek не держит strict json_schema);
  3. ответ прогоняется через ту же логику мягкого парсинга, что `parseLooseJson`;
     при ошибке модели счётчик откатывается (`used = used - 1`);
  4. ошибки DeepSeek переводятся на русский: нет денег / ключ неверный / лимит запросов / сервис недоступен.
- CORS из `npm:@supabase/supabase-js@2/cors`, без JWT — демо работает анонимно.

**Клиент:**
- `src/lib/aiClient.ts` — добавить режим `demo`: вызов `supabase.functions.invoke("demo-braindump")`
  вместо провайдера/встроенного пути. Логика своих ключей не меняется.
- `src/lib/aiProviders.ts` — в конфиг активного подключения добавляется вариант `demo`
  наряду с `builtin` и сохранёнными ключами.
- `src/components/BraindumpPanel.tsx` — переключатель источника, загрузка `status` при открытии,
  показ остатка, блокировка кнопки при исчерпании, сообщения об ошибках.

Демо-путь не касается ни `LOVABLE_API_KEY`, ни ключей из настроек пользователя.
