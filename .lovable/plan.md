# Обновление иконки приложения: плоский минимализм

## Что делаем

Подготовить несколько вариантов новой плоской минималистичной иконки для приложения КОРОБОЧКА. Все варианты сохраняют смысл «коробочка с бумажками» и используют пять акцентных цветов (жёлтый, голубой, зелёный, красный, фиолетовый), но отличаются композицией, формой коробки, расположением бумажек и степенью детализации. Пользователь выберет один вариант, и только после этого мы его внедрим.

## Зачем

- Текущая иконка в репозитории (`public/icon-192.svg`) содержит объёмную крышку, перспективу, четыре развёрнутые бумажки и тёмные обводки — при уменьшении мелкие детали сливаются.
- Для людей с СДВГ важен минимум визуального шума: чистые формы, ограниченная палитра, понятный силуэт.
- Загруженный референс — одно из возможных направлений, но не единственное; сначала предлагаем выбор.

## Этапы

1. **Визуальные варианты.** Сгенерировать 3–4 направления плоской иконки:
   - вариант, близкий к загруженному референсу (округлая коробка + 3 цветные бумажки сверху);
   - вариант с одной большой коробкой и бумажками, выглядывающими из-за края;
   - вариант с коробкой «спереди» и разноцветными уголками бумажек внутри;
   - возможно, вариант с одной доминирующей цветной бумажкой и маленькой коробкой.
   Показать пользователю для выбора.
2. **Выбор и доработка.** Уточнить у пользователя: какой вариант ближе, нужно ли поменять цвета, форму коробки или количество бумажек.
3. **Финальные ассеты.** По выбранному направлению создать:
   - SVG для 192×192 и 512×512;
   - SVG maskable-версии 192×192 и 512×512 с запасом по краям;
   - `favicon.png` 64×64;
   - OG/splash-изображение 1200×630 или 1920×997.
4. **Подключение.** Обновить `<link rel="icon">`, `<link rel="apple-touch-icon">`, `og:image`, `twitter:image` в `index.html`; при необходимости — PWA-манифест.
5. **Проверка.** Собрать проект, убедиться, что иконки отображаются в превью, нет ошибок сборки, favicon подхватывается.

## Критерии готовности

- Пользователь выбрал один из предложенных вариантов.
- Все SVG-иконки — плоские, без градиентов и теней.
- Композиция читается при 192×192 и 64×64.
- Favicon и OG-изображение соответствуют выбранному стилю.
- Сборка (`bun run build`) проходит без ошибок.
