# Коробочка 5.1: чистая панель + окно «Что нового»

## 1. Боковая панель без подписей

В свёрнутом виде (ширина 48px) сейчас под каждой иконкой стоит мелкая подпись («Дом», «Кален.», «Повтор», «Ещё»). Убираем их: остаются только иконки, по центру, с всплывающей подсказкой при наведении. В развёрнутом виде всё остаётся как есть — иконка + полное название.

## 2. Версия 5.1 и окно «Что нового»

- Номер версии меняется на 5.1 везде, где он показан: заголовок в шапке приложения, вкладка браузера и метаданные для шеринга, версия пакета.
- В «Настройках» → «О приложении» появляется строка с текущей версией и пункт «Что нового», который открывает окно вручную в любой момент.
- При первом запуске после обновления автоматически всплывает окно «Что нового в 5.1» со списком изменений понятным языком. Закрывается кнопкой «Понятно», больше не появляется до следующей версии.
- Если пользователь заходит впервые (нет сохранённой версии), окно не показывается — только после реального перехода с прошлой версии.
- Окно умеет показывать изменения не одной версии, а всех, что были пропущены: если человек долго не обновлялся, увидит и 5.1, и последующие.

Содержание записи для 5.1 (по последним изменениям): проекты и чек-листы, режим «С чего начать?» в таймере, повторяющиеся задачи с пояснениями, разгруженная боковая панель и «Настройки» в одном месте, скин «Строгий» для читаемости, размер шрифта.

## Технические детали

- `src/components/AppSidebar.tsx`: убрать поле `short` и ветку рендера подписи в свёрнутом состоянии; отступы кнопок подправить под иконку-центр.
- Новый `src/lib/changelog.ts`: `APP_VERSION = "5.1"` и массив записей `{ version, date, items[] }` в порядке от новых к старым. Единственный источник правды о версии.
- Новый `src/components/WhatsNewModal.tsx`: модальное окно в стиле `SettingsModal` (тот же слой, `z-[10400]`, скругления, кнопка закрытия), показывает все записи новее сохранённой версии.
- `src/App.tsx`: при монтировании сравнить `localStorage["app_version_seen"]` с `APP_VERSION`; если значение есть и меньше — открыть окно; если значения нет — просто записать текущую версию. Заголовок «🎁 КОРОБОЧКА» берёт номер из `APP_VERSION`.
- `src/components/SettingsModal.tsx`: в секции «О приложении» — пункт «Что нового» (проп `onOpenWhatsNew`) и подпись «Версия 5.1».
- `index.html` (title, og:title, twitter:title) и `package.json` version → 5.1.
