# Проекты (чек-листы) + режим «Следующая минута»

Две связанные, но отдельные функции:
1. **Проекты** — группировка задач в упорядоченный чек-лист с шагами (последовательными и параллельными).
2. **Следующая минута** — журнал микро-шагов прямо в таймере, чтобы «сесть и начать», и чтобы видеть, где именно застреваешь.

---

## 1. Проекты

### Что это для пользователя
Новый раздел «Проекты» в левом меню. Внутри — карточки проектов («Проект забора»), у каждого:
- название, категория (цвет/иконка как везде), опционально дедлайн;
- список шагов по порядку (drag & drop, как в общем списке задач);
- у шага метка **«последовательный»** или **«параллельный»**;
- прогресс: «3 из 8».

Логика последовательности (мягкая, не блокирующая):
- Шаги, которые нельзя начать сейчас (перед ними есть невыполненный последовательный шаг), показываются приглушённо с подписью «после: <название шага>».
- Их можно раскрыть и всё равно запустить — приложение не запрещает, только подсказывает.
- Все параллельные шаги доступны всегда.

Связь с остальным приложением:
- Шаг проекта — это обычная задача (тот же тип `Task`), просто с ссылкой на проект и порядковым номером. Значит: она попадает в общий список, в дашборд, в календарь, работает таймер, время и история — ничего нового учить не надо.
- В общем списке и на карточке таймера у такой задачи маленький бейдж с названием проекта.
- **Кнопка «Следующий шаг»** на карточке проекта — сразу запускает таймер на первом доступном шаге. Это главный сценарий: не выбирать, а нажать одну кнопку.
- В случайный выбор задач с дашборда по умолчанию попадают только доступные (не заблокированные) шаги.

Создание: кнопка «Новый проект» → название + категория, затем шаги вводятся построчно (как в модалке добавления задач), потом каждый можно пометить параллельным.

Завершение проекта: когда все шаги выполнены, проект уходит в «Завершённые» внутри раздела.

## 2. Режим «Следующая минута» (в таймере)

По методу из транскрипта: цикл **обязательство → сделать → закрыть время**, плюс честные заметки о том, что мешает.

Где живёт: кнопка «Следующая минута» на экране таймера (и на карточке проекта). Открывает лист внизу экрана:

- Поле: **«Что я делаю в следующую минуту?»** — формулировка-команда, подсказка: «открыть ноутбук», «взять рулетку», «достать чертёж». Есть 3–4 примера-подсказки, чтобы понижать порог.
- После ввода — запись появляется со временем старта и большой кнопкой **«Готово»**, которая ставит время окончания и закрывает шаг (визуально — вычеркнутая строка `10:14–10:22`).
- Кнопка **«Застряла»** → короткая заметка себе + выбор причины из списка: «не понимаю, что делать», «не хватает информации», «скучно / не хочу», «нет условий (место, инструмент)», «другое». Причина сохраняется — это и есть отслеживание прокрастинации.
- Сразу после заметки предлагается следующий микро-шаг с готовым текстом-подсказкой под причину (например, для «не хватает информации» — «найти/загуглить недостающее»).
- Внизу — итог сессии: сколько шагов закрыто, сколько минут суммарно.

Что это даёт помимо самого запуска:
- **Реальная длительность шагов** — видно, что «страшное дело» заняло 12 минут.
- **Разбор прокрастинации**: в разделе «Статистика по времени» добавится блок «Где я застреваю» — топ причин за период и задачи/проекты, где их больше всего.
- В календаре день показывает не только выполненные задачи, но и микро-шаги с временными интервалами.

Метод не навязывается: обычный таймер работает как раньше, «Следующая минута» — отдельная кнопка.

## 3. Откуда берутся подсказки о шагах

Три источника, по возрастанию точности. Приложение всегда сначала показывает то, что работает офлайн, и только по кнопке идёт к ИИ.

### а) Универсальные «стартовые» шаги (всегда есть)
Не зависят от текста задачи, снимают самый частый ступор «не могу сесть»: «открыть/достать то, что нужно», «поставить 5 минут и просто начать», «сделать первое действие руками», «убрать помеху (телефон, посуда, шум)», «записать, что именно непонятно». Плюс подсказки под причину застревания («не хватает информации» → «выписать 1 вопрос и найти на него ответ»).

### б) Библиотека по типам дел (офлайн, встроенная)
Тип определяется по ключевым словам в тексте задачи и по категории. Из вашего списка и типичных дел видно повторяющиеся типы, для каждого — свой готовый чек-лист:

| Тип (ключевые слова) | Пример из вашего списка | Шаги |
| --- | --- | --- |
| Уборка / мытьё / разобрать | «Помыть пол», «Разобрать зимнюю обувь» | освободить поверхность → набрать воду / достать пакеты → 10 минут одна зона → убрать инвентарь |
| Звонок / запись / связаться | «Позвонить в Поиск», «Выбрать гинеколога» | найти номер → написать 1 фразу, что спросить → позвонить → записать ответ |
| Чертёж / замеры / проект | «Чертёж калитки образмерить» | достать рулетку/чертёж → снять 1 размер → нанести на лист → распечатать |
| Готовка / выпечка | «Испечь хлеб» | проверить продукты → достать посуду → замесить → таймер на расстойку |
| Сад / растения | «Пересадить пион» | посмотреть погоду → достать инструмент → выкопать → полить |
| Тренировка / зарядка | «Тренировка в FitStars» | переодеться → открыть приложение и выбрать программу → 5 минут разминки → тренировка |
| Список / планирование | «Составить список блюд» | взять лист → 5 пунктов без раздумий → дополнить → сохранить |
| Документы / оплата / запись | — | найти документ → проверить данные → заполнить → отправить |
| Покупки | — | посмотреть, что кончилось → список → выбрать магазин/сайт → заказать |

Библиотека — обычный файл данных в приложении, её легко пополнять дальше (в том числе задачами второго пользователя, когда вы их пришлёте).

### в) ИИ по кнопке «Предложи шаги»
На карточке задачи и в листе «Следующая минута» — кнопка. Отправляет текст задачи, категорию и (если есть) уже сделанные шаги, получает 3–5 микро-шагов на 1–15 минут, конкретных и физических. Их можно принять целиком, выбрать по одному или отредактировать. Требует интернета; при его отсутствии кнопка неактивна и остаются пункты (а) и (б).

### г) Ваша библиотека шагов
Любой набор шагов — придуманный вручную, выданный ИИ или из встроенной библиотеки — сохраняется как **свой шаблон чек-листа** («Уборка кухни», «Тренировка», «Заказ материалов»). Дальше он применяется к любой задаче одним нажатием, редактируется и удаляется. Свои шаблоны всегда предлагаются выше встроенных, а если название задачи похоже на уже сохранённый шаблон — он подсказывается автоматически. Шаблоны попадают в экспорт/импорт JSON вместе с остальными данными.

### Регулярные дела (уборка, зарядка)
Такие дела нужны как повторяющиеся задачи с готовым чек-листом: создаются один раз (например, «Зарядка» ежедневно, «Уборка кухни» раз в неделю), при выполнении переносятся на следующий период существующей логикой повторов, а чек-лист подтягивается из вашего шаблона. Их удобно добавить как небольшой стартовый набор «Быт и здоровье», который можно принять или отклонить.

## Порядок реализации

Этап 1 — Проекты: модель данных, раздел в меню, список/карточка проекта, шаги с порядком и метками, «Следующий шаг», бейджи в общем списке.
Этап 2 — Следующая минута: лист микро-шагов в таймере, причины застревания, итог сессии.
Этап 3 — Подсказки: универсальные шаги, офлайн-библиотека по типам дел, свои шаблоны чек-листов, стартовый набор регулярных дел.
Этап 4 — Кнопка «Предложи шаги» через ИИ.
Этап 5 — Аналитика: блок «Где я застреваю» в статистике, отображение микро-шагов в календаре.


## Технические детали

- `src/types.ts`: новый `Project { id, title, category, createdAt, deadline?, archived }`; в `Task` добавляются `projectId?`, `stepOrder?`, `stepMode?: "sequential" | "parallel"`. Новый тип `MicroStep { id, taskId?, projectId?, text, startedAt, finishedAt?, note?, blocker?: BlockerKind }`.
- Хранение: проекты и микро-шаги — в существующем IndexedDB (`meta`-store, ключи `projects` и `microSteps`), по образцу `templates`. Задачи-шаги остаются в `tasks`, ничего не мигрируем.
- `src/lib/projects.ts`: вычисление доступности шага (первый невыполненный последовательный шаг блокирует последующие последовательные), прогресс, выбор «следующего шага».
- Новые компоненты: `ProjectsPanel.tsx` (список), `ProjectDetail.tsx` (шаги, drag & drop по образцу `TaskListPanel`), `NextMinuteSheet.tsx` (журнал микро-шагов).
- `AppSidebar.tsx`: `PageId` дополняется `"projects"`; `App.tsx` — маршрут, контекст `projects`/`saveProjects` и `microSteps` рядом с существующими `templates`.
- Валидация импорта JSON в `taskStore.ts` расширяется новыми необязательными полями.
- Стили — существующие семантические токены категорий, размеры шрифтов по действующей схеме `text-xs sm:text-sm`, категории по умолчанию свёрнуты.
- `src/lib/stepHints.ts`: универсальные шаги, словарь типов дел (ключевые слова → чек-лист), сопоставление по тексту задачи и категории, подсказки под причину застревания.
- Свои шаблоны чек-листов: `ChecklistTemplate { id, title, steps: string[], keywords?: string[] }` в `meta`-store (ключ `checklistTemplates`), включены в экспорт/импорт JSON.
- ИИ-подсказки: Lovable Cloud + edge-функция `suggest-steps` (модель `openai/gpt-5.6-sol` через Responses API, стриминг, ключ `LOVABLE_API_KEY` только на сервере). Клиент отправляет текст задачи и категорию, получает 3–5 шагов; при офлайне и при ошибке (429/402) кнопка показывает понятное сообщение, остальные источники подсказок продолжают работать.
