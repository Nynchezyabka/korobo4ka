# Почему не обновляется и что чинить

## В чём дело

Приложение установлено как PWA. Проверка обновлений сейчас работает так: код ждёт сигнала «нужна перезагрузка» от плагина PWA. Но приложение настроено в режиме автообновления (`registerType: "autoUpdate"`) — в этом режиме такой сигнал не приходит вообще. Поэтому кнопка проверки почти всегда отвечает «у вас актуальная версия», даже когда новая версия уже скачана и ждёт установки. Отсюда и приходится удалять приложение и ставить заново.

Второй момент: в манифесте приложения имя до сих пор «🎁 КОРОБОЧКА 5.0», хотя версия уже 5.1.

## Что меняем

1. Определять обновление напрямую по состоянию сервис-воркера, а не по сигналу плагина:
   - при запуске и при ручной проверке смотреть, есть ли уже готовая («ожидающая») новая версия;
   - следить за появлением новой версии в процессе работы.
2. Оставляем поведение «показывать кнопку Обновить»: переключаем регистрацию на режим подсказки (`prompt`), чтобы новая версия не применялась молча, а появлялось уведомление с кнопкой «Обновить». Нажатие — установка и перезагрузка.
3. Раз в 30 минут и при возвращении в приложение (вкладка снова активна) тихо проверять наличие обновления.
4. Честные ответы у кнопки проверки: «есть обновление» / «актуальная версия» / «недоступно» — теперь на основе реального состояния.
5. Имя в манифесте — «🎁 КОРОБОЧКА» без номера версии, чтобы больше не расходилось при каждом релизе.

После этих правок обновление один раз ещё нужно будет получить обычным способом (открыть приложение пару раз или переустановить) — старый сервис-воркер должен смениться на новый. Дальше обновления будут приходить сами с кнопкой.

## Про репозиторий и название

Название проекта в Lovable (korobo4ka) и имя репозитория на GitHub — разные вещи, пересоздавать ничего не нужно:

- Если репозиторий уже подключён: переименуйте его прямо на GitHub (Settings → General → Repository name → Rename). Связь с Lovable сохранится, ничего не сломается.
- Если хочется именно новый репозиторий: в Lovable в меню «плюс» рядом с полем чата → GitHub → отключить текущий, затем подключить заново — будет создан репозиторий с новым именем.
- Публичный адрес приложения (`korobo4ka.lovable.app`) меняется отдельно, при публикации — скажите, если нужно другое имя адреса.

## Технические детали

- `src/lib/pwaUpdate.ts`: `registerSW` с `onNeedRefresh`/`onRegistered` вместо флага; в `onRegisteredSW` сохранять `registration`, проверять `reg.waiting`, слушать `updatefound` + `installing.statechange`, а также `controllerchange` для перезагрузки. `checkForUpdates()` возвращает `available`, если после `reg.update()` есть `reg.waiting` или установленный `installing`.
- Периодическая проверка: `setInterval` 30 мин + слушатель `visibilitychange`.
- `vite.config.ts`: `registerType: "prompt"`, `manifest.name` → «🎁 КОРОБОЧКА».
- UI кнопки обновления (в настройках/сайдбаре) остаётся прежним, просто начнёт получать корректное состояние.
